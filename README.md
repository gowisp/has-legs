# Has Legs

Draft site for Has Legs, a creative extension studio. It is a draft for inspection and is not yet live.

The demonstrations on the page use invented brands (Verlane Bank, Tumble Soda, Okavi Energy) and stand-in artwork. Any resemblance to a real organisation is unintended. Prices and the briefs address are placeholders.

The site is one static page: `index.html`, `styles.css` and `favicon.svg`. There is no build step.
